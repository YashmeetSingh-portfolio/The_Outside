The Outside
Your Portal to the Cosmos: Explore. Discover. Understand.

"The Outside" is an interactive web application designed to bring the wonders of space closer to you. Immerse yourself in a 3D visualization of our solar system, track the International Space Station in real-time, get your daily dose of astronomical beauty with the Astronomy Picture of the Day, test your knowledge with AI-powered space quizzes, and satisfy your curiosity with AI-generated space facts and doubt-solving.

Features
3D Solar System Visualization: Explore our solar system with an interactive and engaging 3D model.
ISS Tracking: Track the International Space Station's live position across the globe.
Astronomy Picture of the Day (APOD): Discover stunning astronomical images and their explanations, courtesy of NASA.
AI Space Themed Quiz: Challenge your knowledge with fun and informative quizzes powered by AI.
AI Space Facts: Learn fascinating facts about space, generated by AI.
AI Space-Related Doubt Solving: Get your space-related questions answered by our AI assistant.

Getting Started
Follow these steps to set up and run "The Outside" on your local machine.

Prerequisites
Before you begin, ensure you have the following installed:

Node.js (LTS version recommended)
npm (comes with Node.js)
Git (for cloning the repository)
1. Clone the Repository
First, clone the project repository to your local machine:

Bash

git clone <your-repository-url-here>
cd TheOutside # Or whatever your project folder name is
2. Frontend Setup
Navigate into the frontend directory and install the necessary dependencies:

Bash

cd frontend
npm install
Environment Variables (Frontend)
Create a .env file in the frontend directory and add the following variable:

VITE_BACKEND_URL=http://localhost:5000
This tells the frontend where to find your backend API.

Run Frontend
Once dependencies are installed and the environment variable is set, start the frontend development server:

Bash

npm run dev
The frontend application should now be accessible in your web browser, usually at http://localhost:5173 (or a similar port).

3. Backend Setup
Open a new terminal window (keep the frontend terminal running) and navigate to the backend directory:

Bash

cd ../backend
npm install
Environment Variables (Backend)
Create a .env file in the backend directory and add the following API keys and MongoDB URI. Replace the placeholder values with your actual keys and URI.

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
NASA_API_KEY=YOUR_NASA_API_KEY
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING
GEMINI_API_KEY: Obtain your API key from the Google AI Studio or Google Cloud Console.
NASA_API_KEY: Get your API key from the NASA API website.
MONGODB_URI: Your connection string for your MongoDB database (e.g., from MongoDB Atlas or a local instance).
Run Backend
Start the backend server:

Bash

node index.js
If you have nodemon installed globally (highly recommended for development as it automatically restarts the server on file changes), you can use:

Bash

nodemon index.js
The backend server will typically run on http://localhost:5000.

Usage
Once both the frontend and backend servers are running, open your web browser and navigate to the frontend URL (e.g., http://localhost:5173) to start exploring "The Outside"!
